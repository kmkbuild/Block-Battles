# Block Battles

Block Battles is a Flutter + Flame mobile puzzle-RPG for Android.

## Tech Stack
- **Language:** Dart
- **App Framework:** Flutter (stable channel)
- **Game Engine:** Flame
- **State Management:** Riverpod
- **Navigation:** GoRouter
- **Persistence:** Hive CE
- **Preferences:** SharedPreferences
- **Audio:** Flame Audio
- **IDE:** Android Studio
- **Target:** Android (portrait, touch)
